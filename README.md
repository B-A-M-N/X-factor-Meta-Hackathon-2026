# X-Factor — Meta Hackathon 2026

A lightweight index of four **independent, modular projects** associated with the Meta Global AI Developer Hackathon 2026.

This is **not a monorepo**. Each project retains its own codebase, dependencies, tests, history, and release process. Inclusion here does not imply that an integration is complete.

| Project | Purpose | Repository |
| --- | --- | --- |
| **Locus** | Local AI inference gateway, routing, and traffic governance | Local project; public repository pending |
| **Ocliv** | Self-hosted HTTPS tunnel and secure remote access | Local project; public repository pending |
| **Metis** | Terminal interface for coding-agent sessions, observation, and guidance | Local project; public repository pending |
| **Jeverb** | Agent decisions, verification, and completion controls | [B-A-M-N/jevwire](https://github.com/B-A-M-N/jevwire) |

## Independence

Each module can evolve and be released on its own. The goal of this index is discoverability and accurate documentation, not forced consolidation or shared runtime dependencies.

## Hackathon work and provenance

Some component code predates the hackathon. Any submission or demo will separately identify the functionality created during the October 27–November 4, 2026 building period; earlier code is not represented as new hackathon work. Eligibility of pre-existing supporting code in the Indie Developer track requires organizer clarification.

This index does not claim that any module or cross-module integration is production-qualified.
